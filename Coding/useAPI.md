##API
**API (Application Programming Interface)** - это набор правил и протоколов, которые позволяют программам взаимодействовать между собой. API определяет, как различные компоненты программного обеспечения должны взаимодействовать друг с другом, какие данные и функции они могут обмениваться, и какие операции они могут выполнять.

API может быть представлен как интерфейс, через который одна программа может обращаться к функциям или данным другой программы. API позволяет разработчикам создавать приложения, которые могут использовать функционал других программ или сервисов, без необходимости знания внутренней реализации этих программ или сервисов.

API используется для интеграции различных приложений, создания расширений и плагинов, а также для доступа к различным сервисам и данным через Интернет. Веб-сервисы, социальные сети, платежные системы и многие другие онлайн-сервисы предоставляют API для удобного взаимодействия с их функционалом.

[Книга API](https://twirl.github.io/The-API-Book/API.ru.html#intro-api-definition)

##Фреймворки

Фреймворк для разработки программных приложений – это среда или набор инструментов и библиотек, который предоставляет разработчику структуру и основные функциональности для создания приложения. Фреймворки облегчают процесс разработки, так как предоставляют готовые решения для типовых задач, а также стандартные методы и правила для работы над проектом.

Фреймворки часто включают в себя функционал для работы с базами данных, веб-серверами, обработки пользовательского ввода, шаблонизации и многих других аспектов разработки приложений
