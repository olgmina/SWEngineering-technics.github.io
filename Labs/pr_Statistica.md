# Статистический анализатор

Программа предназначена для статистического анализа

## Сценарий использования

**Ввод данных:** Пользователь указывает требуемые поля таблицы данных .xmls

**Выполнение расчета** В соотвствии с индивидуальным вариантом и заданными пользователем опциями

**Печать результатов:** Пользователь указывает файл для сохранения результатов в одном из возможных форматов

## Архитектура приложения

Конвейерная обработка данных (Data Pipeline)

Конвейер — это последовательность обработчиков данных, где выход одного обработчика становится входом для следующего.

```text
[ИСТОЧНИК]
↓
┌───────────────┐
│   загрузка файла │     
└───────────────┘
↓
┌─────────────────────┐
│   ПАРСИНГ           │  ← String[] → List<Double>
│   (String → Double) │
└─────────────────────┘
↓
┌───────────────┐
│   подготовка данных     │  ← Объекты для обработки
│   (List<Double>)│
└───────────────┘
↓
┌─────────────────────┐
│   ОБРАБОТКА         │  ← Бизнес-логика
│   (инд. вариант)  │
└─────────────────────┘
↓
┌─────────────────────┐
│   визуализация результата │
└─────────────────────┘
  ← Запись в файл
↓
[ПРИЕМНИК]
```

## Индивидуальные варианты

### 1 Базовый статистический анализ

# Вариант 1: Базовый статистический анализ

**Рассчитать:**
- Среднее арифметическое
- Стандартное отклонение (смещенное/несмещенное)
- Медиана
- Квартили (Q1, Q2, Q3)
- Интерквартильный размах (IQR)
- Выбросы по методу IQR

**Визуализировать:**
- Ящик с усами (Box Plot) с отмеченными выбросами

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

### 2 Анализ распределения

**Рассчитать:**
- Асимметрия (skewness)
- Эксцесс (kurtosis)
- Коэффициент вариации
- Мода (все модальные значения)
- Частоты для интервалов гистограммы

**Визуализировать:**
- Гистограмма частот с наложенной кривой нормального распределения

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

### 3 Робастная статистика

**Рассчитать:**
- Усеченное среднее (trimmed mean)
- Винзоризованное среднее (winsorized mean)
- Медианное абсолютное отклонение (MAD)
- R-оценки (с использованием рангов)
- Отношение среднего к медиане

**Визуализировать:**
- Точечный график (Strip Plot) с маркерами среднего, медианы и усеченного среднего

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

# 4 Проверка гипотез

**Рассчитать:**
- t-критерий Стьюдента (одновыборочный, p-value)
- Критерий Шапиро–Уилка (W-статистика, p-value)
- Критерий знаков (p-value)
- U-критерий Манна–Уитни (p-value)
- Доверительные интервалы (95% и 99%)

**Визуализировать:**
- Q-Q plot (квантиль–квантиль график) с доверительной полосой

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

# Вариант 5. Анализ выбросов

**Рассчитать:**
- Z-оценки для каждого наблюдения
- Выбросы по методу IQR
- Выбросы по методу Z-score (>3σ)
- Процент выбросов в данных
- Эмпирическая функция распределения (ECDF)

**Визуализировать:**
- Скрипичный график (Violin Plot) с выделенными выбросами

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

# Вариант 6 Регрессионный анализ (парный)

**Рассчитать:**
- Коэффициент корреляции Пирсона (r)
- Уравнение линейной регрессии (y = ax + b)
- Коэффициент детерминации R²


**Визуализировать:**
- Диаграмма рассеяния (Scatter Plot) с линией регрессии и доверительным интервалом

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

# Вариант 7 Анализ временных рядов

**Рассчитать:**
- Скользящее среднее (MA, окно задается пользователем)
- Экспоненциальное сглаживание (параметр α)
- Автокорреляция (лаги 1–5)
- Линейный тренд (y = a·t + b)


**Визуализировать:**
- Линейный график: исходный ряд + скользящее среднее + экспоненциальное сглаживание

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown

# Вариант 8 Сравнительный анализ двух выборок

**Рассчитать:**
- Разность средних (Δ = x̄₁ − x̄₂)
- t-критерий для независимых выборок (p-value)
- F-критерий Фишера (p-value)
- Критерий Колмогорова–Смирнова (D, p-value)
- Размер эффекта Cohen's d

**Визуализировать:**
- Сравнительные ящики с усами (Side-by-side Box Plot) с точками средних

**Сохранить:**
- График в форматах PNG, SVG, PDF, HTML
- Таблицы в форматах CSV, Excel, JSON, Markdown
