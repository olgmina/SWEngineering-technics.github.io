# Разработка программного приложения на паттерне Компоновщик


# Варианты индивидуальных заданий

1. Редактор схем электрических цепей. *Идея* Визуальное проектирование электроники. Листья: Резистор, Конденсатор, Транзистор (простые компоненты с выводами). Контейнеры: Микросхема (содержит группу листьев), Блок питания (содержит компоненты и другие микросхемы). Общий метод calculateResistance() / drawCircuit().

2. Система управления задачами (To-Do List) с подзадачамиОрганайзер. *Листья* Простая задача (название, дедлайн, статус). Контейнеры: Составная задача или Проект (содержит задачи и другие проекты). Методы: getProgress(), getTotalTime(). Контейнер суммирует прогресс своих детей.

3. Редактор структуры HTML-документа / XML-файла *Идея* Визуальный конструктор веб-страницы. Листья: Текстовый узел, Изображение, Строка таблицы (<tr>) как атомарный элемент. Контейнеры: Теги-контейнеры (<div>, <table>, <body>), которые могут содержать как листья, так и другие контейнеры. Методы: renderHTML(), addCSSClass().

4. Файловый менеджер / Визуализация файловой системы (утилиту, которая считает размер папки, не задумываясь, папка это или файл — просто вызывая item.getSize(). Отрисовка в GUI может показывать иконки папок и файлов, а при двойном клике по папке (Composite) — открывать её и показывать содержимое)

5. Редактор интеллект-карт Mind Map (Центральная тема (прямоугольник/круг с текстом). От неё отходят ветви. Листья — конечные понятия (прямоугольники). Контейнеры — ветви, которые сами содержат другие ветви и понятия.                                   
Действия пользователя: Перетаскивать целые ветви мышкой (setOnMouseDragged), менять цвет всей ветви и её дочерних элементов, сворачивать/разворачивать ветви (как в вашей лаб с классом).)
