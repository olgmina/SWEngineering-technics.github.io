#  Telegram-бот "Бустер" (Booster Bot)

Разработать Telegram-бота, который помогает студентам поддерживать эмоциональный тонус: хвалит, мотивирует, подбадривает в зависимости от контекста и накопленной статистики.

**Основные функции программы:**

Функциональные требования:

- персонализация обращений (имя пользователя);

- генерация сообщений с учетом контекста; 

- генерация сообщений с учетом предпочтений*; 


Нефункциональные требования:

1) логирование всех видов запросов пользователя (реализуется в спринте 3)

2) хранение данных между перезапусками (реализуется в спринте 3)

3) возможность расширения коллекции комплиментов без изменения кода (реализуется в спринте 1 через JSON)

4) обработка ошибок ввода (реализуется в спринте 1)
    
 
## Сценарий использования по подзадачам

### USER STORY 1: Случайный комплимент (спринт 1)

*Как студент, я хочу получать случайный комплимент, чтобы поднять себе настроение*

Критерии приемки:

- Бот отвечает на команду /compliment

- Комплимент выбирается случайно из коллекции

- Ответ содержит имя пользователя (из профиля Telegram)

- Ответ логируется в консоль

_Технические задачи:_

1. Настройка Spring Boot проекта с Telegram-поллингом

2. Реализация базового обработчика команд

3. Создание коллекции комплиментов (in-memory или ресурсный файл)

4. Интеграция с Telegram API для получения имени пользователя

5. Добавление логирования запросов

_Результат спринта 1_ 

Работающий бот, который отвечает на /compliment случайной фразой с именем пользователя.

Примеры:

"Антон, ты сегодня просто космос! 🚀"

"Лена, у тебя всё получится! Я в тебя верю! 💪"

### USER STORY 2: Контекстный буст (спринт 2)

*Как студент, я хочу получать бусты, соответствующие моему контексту (время суток, день недели, эмоциональное состояние), чтобы чувствовать, что бот понимает мою ситуацию*

**Критерии приемки:**

- Бот учитывает время суток (утро/день/вечер/ночь) при выборе буста
- Бот учитывает день недели (будни/выходные)
- Бот реагирует на ключевые слова в сообщениях (грусть, усталость, успех)
- Вся логика вынесена в отдельные фильтры
- Конвейер фильтров работает как последовательность независимых компонентов

**Технические задачи:**

1. Рефакторинг монолитного обработчика — выделение интерфейса `Filter` и класса `Pipeline`
2. Реализация фильтра `TimeOfDayFilter` (утро/день/вечер/ночь)
3. Реализация фильтра `WeekdayFilter` (будни/выходные)
4*. Реализация фильтра `MoodDetectorFilter` (анализ ключевых слов: грусть, усталость, успех)
5*. Расширение коллекции бустов с разделением по категориям (время, день, настроение)
6*. Модификация `ComplimentGeneratorFilter` для выбора с учетом контекста
7. Сохранение всей функциональности из спринта 1 (регрессионное тестирование)

**Результат спринта 2:**

Работающий бот с конвейерной архитектурой, который учитывает множественные контексты при выборе буста.

**Сценарии тестирования:**

*Сценарий 1: Учет времени суток*

Дано: Системное время 9:00

## Архитектура приложения

Архитектура "Каналы и фильтры"

```text
[Telegram Bot API] 
       ↓
[Dispatcher] — маршрутизация команд
       ↓
[Pipeline фильтров] — конвейер последовательной обработки
       ├── NameExtractorFilter
       ├── TimeOfDayFilter
       ├── MoodDetectorFilter
       ├── ComplimentGeneratorFilter
       ├── PersonalizationFilter
       └── ResponseFormatterFilter
       ↓
[Хранилище данных] — статистика, подписки, история
```


**Dispatcher** — принимает команды от Telegram и направляет их в соответствующий обработчик

**Pipeline фильтров** — конвейер последовательной обработки запроса (паттерн "Каналы и фильтры")

**NameExtractorFilter** — извлекает имя пользователя из профиля Telegram

**TimeOfDayFilter** — определяет время суток (утро/день/вечер/ночь)

**MoodDetectorFilter** — анализирует текст сообщения на наличие ключевых слов (грусть, радость, усталость, успех)

**ComplimentGeneratorFilter** — выбирает подходящий шаблон из коллекции с учетом времени и настроения

**PersonalizationFilter** — подставляет имя пользователя в шаблон

**ResponseFormatterFilter** — добавляет эмодзи, восклицания, форматирует ответ

**Хранилище данных** — сохраняет историю запросов, подписки, статистику
