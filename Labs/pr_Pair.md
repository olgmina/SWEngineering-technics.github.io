# Лабораторная работа 1. Система оповещения о парах

## Этап 1. Разработка MVP

### 🎯 Цель этапа

Создать работающий прототип системы оповещения о парах, используя данные, хранящиеся непосредственно в коде. Это позволит быстро получить работающее приложение и сфокусироваться на логике, не отвлекаясь на работу с файлами.

### 📋 Что такое MVP?

**MVP (Minimum Viable Product)** — это минимальная рабочая версия продукта, которая:

- **Решает основную проблему** пользователя
- **Содержит только критически важные функции**
- **Работает и может быть продемонстрирована**
- **Позволяет получить обратную связь**

**В нашем случае MVP должен:**
1. Показывать ближайшую пару
2. Показывать время до начала/окончания
3. Работать в консоли

**Что НЕ входит в MVP:**
- Графический интерфейс (заменяем консолью)
- Чтение из файла (данные в коде)
- Настройки и оповещения

## Указания по проектированию

🏗️ **Архитектура MVC**

**Model (Модель)** Класс ScheduleModel, который:

- Хранит расписание занятий (список пар с названием, временем начала и окончания)
- Содержит логику определения ближайшей пары на основе текущего времени
- Не зависит от интерфейса

**View (Представление)** FXML-файл ScheduleView.fxml, содержащий:

- Label для отображения информации о следующей паре
- Label для отображения времени до начала/окончания
- Button "Обновить" для ручного обновления информации
- Slider или ComboBox для настройки частоты оповещений (5, 10, 15 минут)
- CheckBox "Отключить оповещения" для временной приостановки оповещений

**Controller (Контроллер)** Класс ScheduleController, который:

- Реализует Initializable
- Связывает View и Model
- Обрабатывает нажатие кнопки обновления
- Настраивает и управляет таймером для периодических оповещений
- Обновляет интерфейс в соответствии с расписанием

## Рекомендации по реализации

1. Создайте проект для приложения с пакетом model

2. Создайте класс Pair (занятие) с полями:
    - String subjectName (название предмета)
    - LocalTime startTime (время начала)
    - LocalTime endTime (время окончания)

3. Создайте класс ScheduleModel и напишите метод Pair findNextPair(LocalDateTime currentTime), который определяет ближайшую пару:
    - Если сейчас идет пара — возвращает текущую пару
    - Если пары нет — возвращает следующую пару
    - Если пар больше нет на сегодня — возвращает первую пару следующего дня

4. Протестируйте логику в main методе

```java
public static void main(String[] args) {
    ScheduleModel model = new ScheduleModel("schedule.csv");
    
    // Тест 1: Текущее время 9:30 (до начала первой пары)
    LocalDateTime testTime1 = LocalDateTime.of(2025, 2, 18, 9, 30);
    Pair nextPair1 = model.findNextPair(testTime1);
    System.out.println("Время: " + testTime1);
    System.out.println("Следующая пара: " + nextPair1);
    
    // Тест 2: Текущее время 11:00 (идет вторая пара)
    LocalDateTime testTime2 = LocalDateTime.of(2025, 2, 18, 11, 0);
    Pair nextPair2 = model.findNextPair(testTime2);
    System.out.println("Время: " + testTime2);
    System.out.println("Текущая пара: " + nextPair2);
    
    // Проверьте, что результаты соответствуют ожиданиям

        System.out.println("✅ Тест 1 пройден!");
    } else {
        System.out.println("❌ Тест 1 не пройден!");
    }
}
```

## Варианты индивидуальных заданий

Варианты форматов хранения расписания

| №  | Формат         | Стиль заполнения | Описание                                         | Пример фрагмента                                                                                        | Сложность |
|----|----------------|------------------|--------------------------------------------------|---------------------------------------------------------------------------------------------------------|-----------|
| 1  | **CSV**        | Компактный (только занятия) | Строки только для реальных пар, пустые пропущены | `Понедельник,09:00,10:30,Математика`<br>`Понедельник,10:45,12:15,Физика`                                | Низкая    |
| 2  | **CSV**        | Полный (все слоты) | Все 8 пар на каждый день с "Нет занятий"         | `Понедельник,09:00,10:30,Математика`<br>`Понедельник,18:15,19:45,Нет занятий`                           | Средняя   |
| 3  | **CSV**        | Матричный (день+8 слотов) | Одна строка на день, 8 колонок с предметами      | `Понедельник,Математика,Физика,Программирование,Английский,Физкультура,,,,`                             | Средняя   |
| 4  | **JSON**       | Объектный с null | Дни как ключи, массивы пар с null                | `"monday": [{"time": "09:00-10:30", "subject": "Математика"}, {"time": "10:45-12:15", "subject": null}]` | Средняя   |
| 5  | **JSON**       | Слотавый (фиксированные слоты) | Фиксированное время, только названия             | `"monday": ["Математика", "Физика", null, null, ...]`                                                   | Низкая    |
| 6  | **XML**        | Иерархический | Дни с вложенными парами                          | `<day name="Понедельник"><pair time="09:00-10:30" subject="Математика"/></day>`                         | Высокая   |
| 7  | **YAML**       | Компактный | Читаемый формат с отступами                      | `понедельник:`<br>`  - {time: 09:00-10:30, subject: Математика}`                                        | Средняя   |
| 8  | **INI**        | Секционный | Дни как секции, пары как ключи                   | `[Понедельник]`<br>`1=09:00-10:30=Математика`<br>`2=10:45-12:15=`                                       | Низкая    |
| 9  | **TXT**        | Фиксированная ширина | Позиционное расположение полей                   | `ПН 09:00-10:30 Математика     `<br>`ПН 10:45-12:15 Физика        `                                     | Низкая    |
| 10 | **PROPERTIES** | Ключ-значение | День+номер как ключ                              | `monday.1=09:00-10:30:Математика`<br>`monday.2=10:45-12:15:`                                            | Низкая    |
| 11 | **CSV**        | Временной (время+дни) | Фиксированное время, предметы по дням            | `09:00-10:30,Математика,Высшая математика,,Базы данных,Экономика,,`                                     | Средняя   |
| 12 | **JSON**       | Смешанный | Объединение времени и предметов                  | `{"times": ["09:00-10:30", "10:45-12:15"], "monday": ["Математика", "Физика"]}`                         | Средняя   |
| 13 | **XML**        | Атрибутивный | Время как атрибут, пустые теги                   | `<pair start="09:00" end="10:30"><subject>Математика</subject></pair>`                                  | Высокая   |
| 14 | **TSV**        | Табулированный | Как CSV с табуляцией                             | `Понедельник	09:00	10:30	Математика`                                                                    | Низкая    |
| 15 | **Markdown**   | Табличный | `                                                | |  Пн       || 09:00-10:30 || Математика ||` | Человекочитаемый |

 Легенда сложности

| Сложность | Описание | Требуемые навыки |
