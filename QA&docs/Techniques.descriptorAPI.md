# API Микросервиса (Название)

## Основная информация

| Описание         | Значение                                  |
|------------------|-------------------------------------------|
| Роль в системе   | Актер или вид пользователя                                 |
| Задача           | Описание проблемы                          |
| Сценарий         | Описание, какую пользу приносит эта задача пользователям |
| Связанные документы | Документы или ссылки с описанием содержимого   |

## Конечные точки и методы

## **Endpoint 1**
  - Метод: GET
  - Параметры запроса: 
    - Параметр 1
    - Параметр 2
  - Формат ответа: JSON

### Параметры запроса

    _Параметры запросов представить подробно в таблице_
    
+ Параметр - название параметра на английском
 
+ Тип данных - указать тип данных параметра с ограничениями по длине если они есть

+ Обязательность - да/нет

+ Описание - понятное описание для чего используется параметр

* Варианты значений - перечислить варианты значений с пояснениями, для чего они используются или привести пример одного из значений

| № | Параметр      | Тип данных       | Обязательность | Описание                     | Варианты значений     |
|---|-------------- |------------------|----------------|------------------------------|-----------------------|
| 1 | id            | number           | нет            | Идентификатор животного      | 11                   |
| 2 | **category**      | object           | нет            | Блок с параметрами по категории | -                   |
| 2.1| category.id  | number           | нет            | Идентификатор категории      | 22                   |
| 2.2| category.name| string           | нет            | Имя категории                | smooth-haired         |
| 3 | name          | string           | нет            | Имя животного                | doggie                |
| 4 | photoUrls     | array of string  | нет            | Фото                         | массив ссылок         |
| 5 | **tags**          | array of objects | нет            | Массив тегов                 | -                     |
| 5.1| tags.id      | number           | нет            | Идентификатор тега           | 10                   |
| 5.2| tags.name    | number           | нет            | Имя тега                    | little                |
| 6 | status        | string           | нет            | Статус                       | available - ожидает, pending - на испытательном сроке, done - пристроено |

###     Проверки
     
     Раздел содержит таблицу:
     Параметр - название параметра на английском
