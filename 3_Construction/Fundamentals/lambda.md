# Task 3.11 Лямбда-операторы в Java

## Теоретическая справка

Лямбда-выражения (лямбда-операторы) в Java – это анонимные функции, которые позволяют передавать поведение как аргумент метода или хранить его в переменной.  Они значительно упрощают написание краткого и читаемого кода, особенно при работе с функциональными интерфейсами.

*Ключевые понятия*:

 __Функциональный интерфейс__: Интерфейс, содержащий ровно один абстрактный метод (может содержать статические и default методы).  
 
 __Лямбда-выражения__ реализуют этот единственный абстрактный метод. 
 Примеры: `Runnable`, `Comparator`, `Callable`.  
 Java предоставляет аннотацию `@FunctionalInterface`, которая позволяет явно указать, что интерфейс предназначен для использования с лямбда-выражениями.  Наличие этой аннотации не является обязательным, но рекомендуется для ясности кода.

 *Синтаксис лямбда-выражения:*

   ` (параметры) -> тело `

    Параметры: Список параметров, заключенный в круглые скобки. Если параметров нет, скобки можно опустить.  Типы параметров могут быть указаны явно или опущены, если компилятор может вывести их из контекста.

    ->: Символ стрелки, разделяющий параметры и тело лямбда-выражения.

    Тело: Выражение или блок кода, который выполняется лямбда-выражением.  Если тело состоит из одного выражения, фигурные скобки можно опустить, и результатом выражения будет результат выполнения лямбда-выражения. Если тело содержит несколько операторов, оно должно быть заключено в фигурные скобки `{}`, и в этом случае необходимо явно указать оператор `return`.

Преимущества использования лямбда-выражений:

- Краткий и  компактный код, что улучшает читаемость.
- Поддержка функционального стиля программирования, что позволяет писать более модульный и тестируемый код.
 
## Примеры 

1. Использование "стандартного" интерфейса Runnable, Comparator

```java
Runnable r1 = () -> System.out.println("Hello from lambda!");
new Thread(r1).start();

// Более короткий вариант:
new Thread(() -> System.out.println("Hello from lambda!")).start();
```

```java
List<String> strings = Arrays.asList("apple", "banana", "orange");
strings.sort((s1, s2) -> s1.compareTo(s2)); // Сортировка по алфавиту
System.out.println(strings);

strings.sort((s1, s2) -> s2.length() - s1.length()); // Сортировка по длине строки (в обратном порядке)
System.out.println(strings);
```

2.  Возврат значения из функции

```java
Function<Integer, Integer> square = x -> x  x;
System.out.println(square.apply(5)); // Вывод: 25

Function<String, Integer> stringLength = String::length;
System.out.println(stringLength.apply("hello")); // Вывод: 5
```

3. Использование метода по ссылке, как краткий способ передать существующий метод в качестве лямбда-выражения.  
Они используют оператор `::`.

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(System.out::println); // Вывод каждого элемента на консоль
```
